# 📄 Automated Resume Parser

An AI-powered resume parser built with Python, spaCy & Streamlit. Extracts
Name, Email, Phone, Skills, Education & Experience from PDF/DOCX resumes.
Stores candidates in SQLite with search, filter & CSV/JSON export.


## ✨ Features

- 📤 Upload PDF or DOCX resume
- 🔍 Extracts Name, Email, Phone, Skills, Education & Experience
- 🗃️ Stores candidates in SQLite database
- 🔎 Search and filter candidates
- 📥 Export data as CSV or JSON


## 🧠 Tech Stack

- Python
- spaCy
- NLTK
- PyMuPDF
- SQLite
- Streamlit


## 📊 Models Used

- spaCy NER for entity extraction
- TF-IDF for job matching score
- Regex for contact info extraction
- Cosine Similarity for ranking


## ▶️ Run Locally

git clone https://github.com/dheeraj815/Automated-Resume-Parser.git
cd Automated-Resume-Parser
pip install -r requirements.txt
streamlit run app.py
